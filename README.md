# ValueCodex · GPT 估值推演工作台

一个纯本地运行的 Codex 风格「思考 + 企业估值」模拟器。无需安装依赖，双击 `index.html` 即可使用。

## 功能

- **四种推演模型**：GPT-5.1-Codex、o3、GPT-4.1、GPT-4.1 mini，可在顶栏或命令面板切换。
- **四档思考强度**：低 / 中 / 高 / 极高。强度越高，推演步骤、蒙特卡洛路径和 token 估算越多，极端档位会触及 32,000 条路径上限；同时档位决定「估值口径」（快速 / 标准 / 交叉复核 / 深度压测）。
- **模型口径会移动估值**：每个模型有自己的口径 —— GPT-5.1-Codex 交叉校验、o3 保守前移、GPT-4.1 基准对齐、GPT-4.1 mini 乐观速览，各自对应不同的相对估值权重与口径折溢。同一套假设切换模型，综合公允价值会随之变化；报告中的「口径对比」卡与 Markdown 表格会列出四个模型在当前强度下的结果。
- **DCF 估值工作台**：五年自由现金流、Gordon 永续终值、EV/Sales 相对估值交叉校验，输出综合公允价值、P10–P90 区间、情景分析、敏感性矩阵与现金流明细。
- **可调假设**：营收、增速、利润率、税率、WACC、永续增速、净现金、股本、市价、D&A、CapEx、营运资金、退出倍数与不确定性系数。
- **本地推演记录**：自动保存最近 6 次结果到浏览器 `localStorage`，可点击恢复。
- **报告导出**：一键复制 Markdown 摘要或导出 `.md` 文件。
- **自定义标的**：内置 NovaCloud、Helios Energy、Mori Foods、Arclight Semi 四个合成案例，也可新建 / 编辑标的。
- **响应式界面**：桌面工作台、平板抽屉、手机单栏布局。

## 使用

1. 直接打开 `index.html`（推荐 Chrome / Edge）。
2. 选择模型与思考强度。
3. 在右侧「估值假设」中调整参数；底部会实时预览公允价值。
4. 点击「运行估值」（`Ctrl/⌘ + Enter`），或从命令面板执行。
5. 查看报告，必要时继续追问或导出 Markdown。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + K` | 打开命令面板 |
| `Ctrl/⌘ + Enter` | 运行 / 停止推演 |
| `N` | 新建标的 |
| `Esc` | 关闭弹窗、面板或抽屉 |

## 重要说明

- 全部数据与计算都在本地完成，不调用任何网络接口。
- 这是**估值逻辑与交互的模拟器**，不是投资建议，也不连接真实行情。
- 模型和思考强度决定**估值口径**（相对估值权重 + 口径折溢 + 区间收放），因此会真实影响综合公允价值；但它们不改动右侧的 DCF 基准假设与现金流公式。报告里同时给出「原始口径」值，便于对比纯 DCF 结果。
- 当 WACC 与永续增速过近时，模型会自动把计算用 WACC 上调，并在报告中标注。
- 当退出倍数设为 `0` 时，相对估值自动关闭，综合公允价值退化为 100% DCF。
